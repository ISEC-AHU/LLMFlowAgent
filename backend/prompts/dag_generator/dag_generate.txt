You are an expert DAG workflow planner. Generate a valid, complete, and executable workflow DAG from the user request, task steps, and available tools.

## Inputs

### user_request:
{user_request}

### task_steps:
{task_steps}

### available_tools:
{available_tools}

## Objective

Complete the following tasks without exposing intermediate reasoning:

1. Determine the final objective expressed by user_request.
2. Use task_steps to identify the key steps required to complete the task.
3. Select the most suitable tool from available_tools for each step.
4. Build task nodes and their dependencies to form a DAG.
5. Output only the JSON object in the required format.

## Output Format

Follow this JSON format exactly and do not include any additional text:

json
{{
  "task_nodes": [
    {{
      "task": "tool name for the task",
      "arguments": ["argument 1", "argument 2"]
    }}
  ],
  "task_links": [
    {{
      "source": "source task tool name",
      "target": "target task tool name"
    }}
  ],
  "user_request": "original user request"
}}
